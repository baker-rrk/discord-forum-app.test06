## Web版に取り込めなかったもの
- `[📁 ローカル資料・BGM]`（PC上のファイルの絶対パスを記録し、標準ソフトで開く）… ブラウザからはPCのファイルを開けません
- PDFのテキストを、あらすじへ自動入力 … PDFを読む外部ライブラリが必要なため見送り（希望があれば、CDNから読み込む形で追加できます）
- `zipview://` の参照（解凍せずにZIP内の画像を表示）… Electron専用。デスクトップ版で登録した画像（zipview:// / file://）は、データとしては引き継がれますが、Web版では表示・使用できません（使おうとするとお知らせします）

## ZIPの読み取りについて
- 対応：ZIP内の png / jpg / jpeg / gif / webp / bmp（deflate・無圧縮）
- 除外：フォルダ、`__MACOSX`、「.」で始まる隠しファイル、暗号化されたファイル、30MBを超えるファイル。上限300枚
- ZIP64形式は未対応。日本語の名前（Shift_JIS）も読めます
- 画像は2.5MBを超えると、長辺1920pxに縮小して保存します

## test59：STEP 2（PDFからのスペック自動推測とスマートD&D登録）
- **ドロップ先**：🏠 ホーム／📝 投稿・編集画面の全体（既存の専用ドロップ欄が処理するものは、従来どおり）。フォルダ・ZIP・PDFに対応
  - **1件だけ**：登録後すぐ、そのシナリオの投稿・編集画面へ（推測内容を確認・修正）
  - **複数件**：画面は移らず一括登録し、「〇件のシナリオを追加しました」
  - **同名シナリオ（クレンジング後）**：新規作成せず「既存シナリオ『〇〇』に画像・PDF素材を追加（マージ）しますか？」。承認で既存のギャラリー・PDFへ統合（シナリオ本体の項目は変えない）
  - 投稿・編集画面でシナリオを開いたまま1件ドロップ：新規作成はせず、開いているシナリオへ素材を追加（確認あり）。画像だけなら、そのシナリオのギャラリーへ
- **推測の流れ**：メインPDFの判別（KP・真相・データ・HO・規約・おまけ等はサブ／「本編」「本文」、フォルダ名に近いものをメイン）→ 名前のクレンジング（先頭のひらがな1文字＋空白、人数・システムの括弧、ver表記）→ PDF 1〜2ページ目の最大フォントの文字列と照合（フォルダ名を優先。PDF側が「サブタイトル付きで詳しい」ときはPDFの表題。ファイル名が「本編」などの汎用名なら、PDFの表題）→ 1〜5ページの文字から 人数・時間・推奨技能・ロスト率・あらすじ（ほか必須・準推奨技能、後遺症、システム）を抽出 → トレーラー画像（trailer／トレーラー／title／タイトル／サムネ／cover／表紙、次点で「01」）
- **保存**：PDF本体は IndexedDB（assetStore）、シナリオには `pdfs`（参照キー・名前・サイズ・メイン/サブ）。画像はサブフォルダ名がカテゴリ、トレーラー画像は「トレーラー」、その他は「未分類」。**PDF本体は端末内のみ**（JSON・クラウドへは参照だけ。他の端末では「この端末にファイルがありません」と表示）
- **pdf.js**：`index.html` で CDN（cdnjs, pdfjs-dist 3.11.174）から読み込み。読めない場合も、PDFの保存・紐づけは行い、スペックの推測だけを諦めます（人数・システムはフォルダ名の表記から補う）。縦書きPDF・スキャン画像だけのPDFの文字は読めません
- シナリオ詳細・編集画面のギャラリー欄に「📄 登録PDF」を表示（開く／削除）。シナリオを削除すると、ほかで使われていないPDF本体も端末から削除

## test59：STEP 3（♟️ ココフォリア準備・PDFビューア・高精度テキスト抽出）
- **画面**：左サイドバー「♟️ ココフォリア準備」。上部で対象シナリオを検索して選ぶ（↑↓Enter／システム名・タグでも検索）。「✕ 選択解除」でワンクリックで未選択へ。ホームのシナリオ詳細の「♟️ ココフォリア準備で開く」からも入れる
- **データ**（軽量なJSON）：`{ texts（シナリオテキスト）, npcs（NPC）, pieces（キャラクター駒／オブジェクト駒） }`。シナリオ選択中は `sc.ccfolia`、未選択のときは `appState.ccfolia`。どちらも Firebase同期・JSONエクスポート・JSON統合・読み込み時の検証の対象。未選択で作ったデータは、一覧の「➡ 移動（紐づけ）」「⧉ 複製」で任意のシナリオへ（シナリオ間の複製も同じ操作）
  - 未選択領域のクラウド統合は「同じidは今のもの、無いものは追加」（削除は他の端末へ伝わりません）
- **PDFビューア**（左ペイン）：登録PDFをドロップダウンで切り替え（メインに★）／連続縦スクロール／拡大・縮小・幅に合わせる／マウスドラッグのテキスト選択と「▭ 矩形選択」（枠は、選択後・Esc・ページ外・ウィンドウ移動のいずれでも必ず消える）／PDF内検索（件数・▲▼・ハイライト・ジャンプ）／「📂 開く」「ドロップ」でPCのPDFを一時的に開く
- **別ウィンドウ**（「↗ 別窓」）：`window.open` で開いた同じオリジンのウィンドウの中に同じビューアを作る方式（file:// で開いても動くよう、BroadcastChannel／postMessage は使わず、メイン画面の関数へ直接つなぐ）。別窓では 単ページ／見開き2ページ／縦スクロールの切り替えができ、選んだ文字は即座にメイン画面の抽出欄へ届く。メイン画面を閉じると別窓も閉じる
- **座標ベースの抽出**：選択範囲の文字（座標・サイズつき）から ①ルビ除外（本文サイズ＝文字数で重みを付けた中央値の70%未満を除外・既定ON）②2段組の自動整列（Xの分布に中央の隙間があれば 左段→右段の順・既定ON）③1行目の自動タイトル化（30文字以下、または 【 ▼ ■ ◆ ● などで始まる行・既定ON）。トグルを切り替えると、選択をやり直さず再計算。直前の内容へ「↩ 戻す」
- **整形ツール**：不要な改行・空白の一括除去／英数字の半角⇄全角／指定語の一括 `{}` 変数化（HO1 → {HO1}。すでに {} のものは二重にしない）
- **登録**：既定は「純粋なシナリオテキスト」。任意で「👤＋ 関連するキャラクター駒／オブジェクト駒を同時に作成」（名前・専用ギャラリーのアイコン）。NPC・駒は一覧のフォームからも追加・編集
- **注意**：PDFの描画・文字の取得は pdf.js（CDN）を使います。日本語PDF用の cMap・標準フォントは jsDelivr（pdfjs-dist 3.11.174）から取得します（STEP 2 の推測にも同じ設定）。回転したページ・縦書きPDFの文字の座標は未対応です

## test59：ドロップ周りの不具合修正（フォルダの読み取りエラー／タイトル推測）
- **フォルダのドロップ**：①`drop` の処理中（最初の `await` より前）に、`dataTransfer.items` と `files` を配列へ吸い出す（`snapshotDrop`）②`readEntries` は空の配列が返るまで繰り返し、1ファイル・1サブフォルダが読めなくても、ほかは取り込む（読めなかった件数は通知）③ルートの走査が拒否（SecurityError など）される／空に見える場合は、フォルダ選択ダイアログ（`<input webkitdirectory>`）へ誘導。`file://` で開いているときは、その旨と「http://localhost などのローカルサーバー経由で開く」案内も表示。フォルダをFileとして渡すブラウザも検出。ホームに「📁 フォルダを選んで登録」「📄 PDF・ZIPを選んで登録」ボタンを追加（ドラッグ＆ドロップが使えない環境でも、同じ取り込み・クレンジングを通る）。シナリオ詳細・ギャラリー欄のドロップ（`galleryDrop`）にも同じ対策を適用
- **タイトルの推測**：名前のクレンジングを、a 拡張子 → b 先頭の頭文字（かな・英字1〜2文字／数字1〜3桁＋区切り）→ c 人数の括弧（全角にも対応。括弧の中に他の語が混じっていても、まるごと）→ d システム名・素材種別の括弧、`_本文`・`_素材`・ver 等の末尾、`SPLL_E103007_` のような配布IDの頭、の順に実施（`19_scenario_guess.js` の `analyzeName`。すべての取り込みがここを通る）。PDF 1〜2ページ目の最大フォント文字列にも同じクレンジングを通し、取れたらそれをタイトルに採用（周りより明らかに大きい文字が無い場合は「表題なし」）。「クトゥルフ神話TRPG」「Call of Cthulhu」「目次」「利用規約」など定型句しか取れなければ、クレンジング済みの名前を維持。登録後は一覧・選択肢・編集画面の入力欄を描き直す
- 先頭の頭文字の除去は、外したあとに文字が残らない場合（例：`ある (1)`）は行いません。英字2文字までの先頭語（例：`My Story`）は、仕様どおり頭文字として除去されます

## test59：STEP 4（NPC自動生成・マルチシステムのチャパレ・ダミー駒・駒ZIP）
- **先頭文字のクレンジング**：除去は「ひらがな・カタカナ1文字＋区切り」「数字1〜3桁＋区切り」のみ。英字（`A Story`・`My Story`・`In ...` など）は1文字から全部そのまま残す
- **👤 NPC駒を錬成**：抽出テキスト（またはPDFで選んだ範囲）から、名前／ステータス（HP・MP・SAN・SP・装甲・幸運・生命力・共鳴）／パラメータ（STR〜EDU・DB。「項目名の行＋数字の行」の表形式にも対応）／技能を自動抽出して、確認・微調整モーダルを開く。技能の形式：`目星:50%`・`聞き耳 60%`・`《言いくるめ》(85)`・`図書館(70)`、および ダイスコマンドの逆引き（`CCB<=70 【こぶし(パンチ)】`・`CC<=60 目星`・`2D6>=5 【調査】`・`2DM<=4 〈洞察〉`。名前の中の丸括弧は残す）
- **🔍 PDFからNPCを一括検出**（ビューアのツールバー）：登録された全PDF・全ページを走査（2段組・ルビ除外あり）。ステータス・技能が密集したブロック（「■名前」などの見出しで分割）を候補として一覧表示し、チェックしたものを一括登録
- **🎲 ゲームシステム**（シナリオ／未選択領域の既定＋NPCごと）：CoC6版／CoC7版／エモクロア／インセイン・シノビガミ(2D6)／SW2.5／DX3rd／カスタム。共通：シークレットダイス（先頭 `s`）・ステータス非公開（hideStatus）
  - CoC6：`CCB<=値 【技能】`／拳銃などの連撃 `x2`（`sx2`）を併記するオプション／マーシャルアーツ・武道 × こぶし・キック等の `CBRB(A,B)` を自動併記＋任意の2技能の CBRB 追加／STR・CON・POW・DEX があれば末尾に `RESB({STR}, ) STR対抗`（相手は空欄。`{STR}` はキャラクターのパラメータ参照）
  - CoC7：`CC<=値 【技能】`＋ハード/イクストリーム、ボーナス/ペナルティダイス（`CC(1)` / `CC(-1)`）　エモクロア：`{Lv}DM<=判定値 〈技能〉`　2D6：`2D6>=目標値(既定5) 【特技】`　SW2.5：`2D6+値 【技能】`　DX3rd：`{ダイス}DX+値@10 【技能】`　カスタム：`{name} {value} {half} {fifth}` のテンプレート
- **一覧の整理**（シナリオテキスト・NPC・駒）：ドラッグ＆ドロップの並べ替え（並び順が「手動」のとき）、キーワード絞り込み（例：HO1）、名前順・新しい順・古い順、表示中の全選択、チェックした項目の一括削除。立ち絵は専用ギャラリーから選び、サムネイルは顔（`object-position: top center`）にフォーカス
- **ダミー駒**：チェックした複数のシナリオテキストを、1つに統合せず、それぞれ独立した駒に（メモ＝改行を保った原文、チャパレ＝改行を消した1行）

  - ⚠️ **ココフォリアの取り込み形式には公式の仕様書が無く**、広く知られているルームデータの構造（`entities.characters`＋`resources`）に合わせた推測です。ZIPをココフォリアにドロップして取り込めない・画像が付かない場合は、形式の組み立て（`25_ccfolia_export.js` の `toCharacter()` / `buildDataJson()`）だけを直せば対応できます
